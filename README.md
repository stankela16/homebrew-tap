# Homebrew Tap for `agymg`

Official [Homebrew](https://brew.sh) tap for **[agymg](https://github.com/stankela16/agymg)** — Unified MCP, Skills & Plugins Control Center for **Claude Code** & **Google Antigravity** on macOS 14+.

## Install

```bash
brew install stankela16/tap/agymg
agymg install-app
```

> **Requirements**: macOS 14.0+ (Sonoma or Sequoia) and Xcode Command Line Tools (`xcode-select --install`).

## Upgrade

```bash
brew update
brew upgrade agymg
agymg install-app
```
